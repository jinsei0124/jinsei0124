## 🚀 最近の活動

**インターンシップへの参加（2026年夏）**
ミネベアソフトウェアソリューションズ、株式会社ソニックス、朝日信用金庫のインターンに参加。AIを活用した日報自動生成アプリの開発や、UI/UXを重視したアプリの要件定義、金融業務における顧客のビジネス課題解決ワークなどを実践しました。

**JANOG57への参加（2026）**
若者支援プログラムを利用してJANOG57に参加。セッションの聴講やベンダーブースの見学、第一線のエンジニアとのネットワーキングを通じてインフラ・ネットワーク技術の知見を広げ、事後レポートの作成まで完遂しました。

**プロジェクト開発**
Google Sitesを用いた福祉情報共有・ゲーミフィケーションアプリ「FAQuest」の企画・プレゼンテーション資料作成を進行中。過去には、Google Cloud Translation APIを用いた簡易翻訳アプリや、機械学習による画像分類アプリなどを開発しました。

**就職活動**
インターンシップ経由での選考に向けた履歴書・自己紹介書のブラッシュアップや、テストセンターでの適性検査に向けた準備を進行中。同時に、応用情報技術者試験の取得に向けた学習も視野に入れています。
